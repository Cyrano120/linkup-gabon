# Screenshots

Dépose ici tes captures pour le README :

- `screenshot-home.png` — page d'accueil (hero + sections)
- `screenshot-market.png` — page Services / prestataires (optionnel)
- `screenshot-missions.png` — page Missions (optionnel)

Comment faire :
1. Lance `npm run dev` → http://localhost:5173
2. Capture en 1280x800 (outil Capture Windows : Win+Shift+S)
3. Enregistre le fichier sous le nom exact ci-dessus
4. Commit + push — le README l'affichera automatiquement
